COW Shed contracts are deployed to deterministic addresses across multiple EVM-compatible chains using CREATE2. This ensures consistent addresses for easier integration and user experience.

## Overview

The following contracts are deployed:

- **COWShed**: The main proxy implementation contract
- **COWShedFactory**: Factory contract for deploying user-owned proxies
- **COWShedForComposableCoW**: Specialized version with Composable CoW support (Gnosis Chain only)

## Deterministic Deployment

<Info>
  All contracts are deployed using CREATE2 with a zero salt (`bytes32(0)`), ensuring the same addresses across chains. This makes integration easier and provides a consistent user experience.
</Info>

The deterministic deployment approach means:

- **Predictable Addresses**: Users can know their proxy address before deployment
- **Cross-Chain Consistency**: Same addresses on different chains simplify integrations
- **Gas Efficient**: Users only pay for deployment when they first use the proxy
- **Lazy Deployment**: Proxies are deployed on-demand during the first hook execution

## Verifying Contracts

All deployed contracts are verified on their respective block explorers. You can view the source code, read contract state, and interact with the contracts directly through the explorer interfaces.
