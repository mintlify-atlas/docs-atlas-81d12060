# COWShed Contract

The COWShed contract is the core implementation contract that provides authenticated hook execution functionality for CoW Protocol orders. It implements the `ICOWAuthHook` interface and provides secure execution of arbitrary calls with signature verification, nonce management, and pre-signing capabilities.

**Source:** `~/workspace/source/src/COWShed.sol`

## Core Functions

### initialize

```solidity
function initialize(address factory) external
```

Initializes the COWShed proxy with the factory address as the initial trusted executor. Can only be called once.

<ParamField path="factory" type="address">
  The address of the COWShedFactory contract that will be set as the trusted executor
</ParamField>

<Note>
  This function can only be called once. Subsequent calls will revert with `AlreadyInitialized()`.
</Note>

**Emits:** `TrustedExecutorChanged(address(0), factory)`

**Errors:**
- `AlreadyInitialized()` - If the contract has already been initialized

---

### executeHooks

```solidity
function executeHooks(
    Call[] calldata calls,
    bytes32 nonce,
    uint256 deadline,
    bytes calldata signature
) external
```

Executes a set of calls after authenticating the signature, verifying the nonce hasn't been used, and checking the deadline hasn't passed. This is the primary function for executing authenticated hooks.

<ParamField path="calls" type="Call[]">
  Array of calls to execute. Each call includes target, value, callData, allowFailure, and isDelegateCall flags
</ParamField>

<ParamField path="nonce" type="bytes32">
  Unique nonce to prevent replay attacks. This nonce will be marked as used
</ParamField>

<ParamField path="deadline" type="uint256">
  Unix timestamp after which the signature is no longer valid
</ParamField>

<ParamField path="signature" type="bytes">
  EIP-712 signature from the admin authorizing these hooks
</ParamField>

**Access:** Anyone can call this function if they have a valid signature from the admin

**Errors:**
- `InvalidSignature()` - If the signature verification fails
- `NonceAlreadyUsed()` - If the nonce has already been consumed

**See also:** `ICOWAuthHook.sol:17`

---

### executePreSignedHooks

```solidity
function executePreSignedHooks(
    Call[] calldata calls,
    bytes32 nonce,
    uint256 deadline
) external
```

Executes a set of hooks that have been pre-signed on-chain using `preSignHooks()`. This allows for gasless execution patterns.

<ParamField path="calls" type="Call[]">
  Array of calls to execute
</ParamField>

<ParamField path="nonce" type="bytes32">
  Unique nonce for the hooks
</ParamField>

<ParamField path="deadline" type="uint256">
  Unix timestamp deadline for execution
</ParamField>

**Access:** Anyone can call this function if the hooks have been pre-signed by the admin

**Errors:**
- `NotPreSigned()` - If the hooks haven't been pre-signed
- `NonceAlreadyUsed()` - If the nonce has already been consumed

**See also:** `COWShed.sol:103`

---

### trustedExecuteHooks

```solidity
function trustedExecuteHooks(Call[] calldata calls) external onlyTrustedRole
```

Executes arbitrary calls without signature verification. Only callable by the admin or trusted executor.

<ParamField path="calls" type="Call[]">
  Array of calls to execute
</ParamField>

**Access:** Only admin or trusted executor

**Errors:**
- `OnlyTrustedRole()` - If caller is neither admin nor trusted executor

<Warning>
  This function bypasses signature verification and should only be callable by highly trusted addresses.
</Warning>

**See also:** `COWShed.sol:117`

## Pre-Signing Functions

### preSignHooks

```solidity
function preSignHooks(
    Call[] calldata calls,
    bytes32 nonce,
    uint256 deadline,
    bool signed
) external onlyAdmin
```

Pre-signs a set of hooks on-chain, allowing them to be executed later without an off-chain signature. Can also revoke pre-signatures by setting `signed` to false.

<ParamField path="calls" type="Call[]">
  Array of calls to pre-sign
</ParamField>

<ParamField path="nonce" type="bytes32">
  Unique nonce for the hooks
</ParamField>

<ParamField path="deadline" type="uint256">
  Unix timestamp deadline
</ParamField>

<ParamField path="signed" type="bool">
  True to pre-sign, false to revoke a pre-signature
</ParamField>

**Access:** Only admin

**Errors:**
- `OnlyAdmin()` - If caller is not the admin
- `PreSignStorageNotSet()` - If pre-sign storage has not been initialized

**See also:** `COWShed.sol:92`

### resetPreSignStorage

```solidity
function resetPreSignStorage() external onlyAdmin returns (IPreSignStorage)
```

Creates and sets a new pre-sign storage contract. The first time this is called, it enables pre-signatures. Subsequent calls invalidate any pending pre-signatures but keep pre-signing enabled.

<ResponseField name="storageContract" type="IPreSignStorage">
  The newly deployed PreSignStateStorage contract
</ResponseField>

**Access:** Only admin

**Emits:** `PreSignStorageChanged(address storageContract)`

**Errors:**
- `OnlyAdmin()` - If caller is not the admin

**See also:** `COWShed.sol:66`

## Administrative Functions

### updateTrustedExecutor


Updates the trusted executor address. Can only be called by the contract itself (must be executed through `executeHooks` or similar).

**Access:** Only callable by the contract itself (via delegatecall)

**Emits:** `TrustedExecutorChanged(address prev, address who)`

**Errors:**
- `OnlySelf()` - If caller is not the contract itself

**See also:** `COWShed.sol:122`

---

### updateImplementation

```solidity
function updateImplementation(address newImplementation) external onlyAdmin
```

Updates the implementation contract for the proxy. This allows upgrading the COWShed logic.

<ParamField path="newImplementation" type="address">
  The address of the new implementation contract
</ParamField>

**Access:** Only admin

**Emits:** `Upgraded(address indexed implementation)`

**Errors:**
- `OnlyAdmin()` - If caller is not the admin

<Warning>
  Upgrading the implementation affects all future calls to the proxy. Ensure the new implementation is thoroughly tested.
</Warning>

**See also:** `COWShed.sol:132`

---

## View Functions

### domainSeparator


<ResponseField name="separator" type="bytes32">

```solidity
  domainTypeHash,
  keccak256(bytes("COWShed")),
  keccak256(bytes(VERSION)),
  block.chainid,
  address(this)
))
```

## Usage Example

```solidity
// Execute hooks with signature
Call[] memory calls = new Call[](1);
calls[0] = Call({
    target: token,
    value: 0,
    callData: abi.encodeCall(IERC20.approve, (spender, amount)),
    allowFailure: false,
    isDelegateCall: false
});

bytes32 nonce = keccak256(abi.encodePacked("unique-nonce"));
uint256 deadline = block.timestamp + 1 hours;

// Sign off-chain with admin's private key
bytes memory signature = signExecuteHooks(calls, nonce, deadline, adminPrivateKey);

// Execute
cowshed.executeHooks(calls, nonce, deadline, signature);
```
